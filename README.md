# MANGO-WEBSITE
# 🥭 Mangolicious — Premium Mango Creamery Website

## ✨ Project Overview

Mangolicious is a modern and visually immersive premium dessert website designed with advanced **HTML, CSS, and JavaScript**.
This project focuses on delivering a luxurious user experience with elegant animations, interactive UI elements, and a vibrant mango-inspired design aesthetic.

The website showcases a fictional artisan mango creamery brand that specializes in handcrafted mango desserts made from premium Alphonso mangoes.
